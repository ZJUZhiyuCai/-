## 完整版发布门槛

1. 建立可公开分发的自有样本集：每项注解至少一个最小正例、边界例、错误例；组合样本覆盖中文图书、科技公式、表格、辞书注释、竖排典籍、多栏期刊。原版手册截图或素材不作为开源资产。
2. 区分三种兼容：文件无损读写、注解语义、版面一致。每项有独立测试结果；不允许“能打开”替代“正确排版”。
3. 对照环境记录原版版本、输入SHA-256、字体文件及版本、纸张参数、输出文件、截图/几何数据。先确认参考版本和字体可用，再做差分。
4. 页数、换行、分页、内容顺序和表格结构采用精确检查；文字/线/图片边框位置建议误差≤0.2mm，字体轮廓另行评估并说明误差来源。该阈值是本项目建议，非手册规定。
5. PDF输出按实际印刷工作流验证字体嵌入、透明度、颜色空间、尺寸、图像质量；通过预检才可称印刷可用。浏览器“另存PDF”自身不证明上述条件。
6. 可靠性：1000页压力样本、持续编辑与恢复、撤销/重做、损坏工程、缺字/缺图、异常取消、不受信输入；记录机器规格、耗时、内存和恢复结果，不预先填造指标。
7. 所有条目标记已实现且通过对应测试，或发布说明显式缩减范围。未通过项继续标记不支持/实验性；在大项缺失时不得称“方正书版完整兼容”。
