# FBD / BD 导入范围与证据

本模块是独立编写的 MIT JavaScript 解析器，只实现很小的文本子集。它不是方正书版引擎的移植，不包含原程序代码、字库或商业样例正文，不承诺版面或文件完全兼容。测试文本全部自创。

## 接口与行为

`parseFbd(decodedText)` 接收已解码字符串，返回 `{ blocks, warnings, layout? }`。`layout` 仅在整篇简单分栏被识别时提供，调用方应合并到默认版式。调用方应保存原始文件或原始文本；这是单向的近似导入，并非可逆格式转换。旧样例使用 Windows GBK / CP936 解码，可用 `new TextDecoder('gbk', {fatal:true}).decode(bytes)`。不能仅凭扩展名保证所有 FBD 文件都用这一编码；也不能把 UTF-8 内容直接当 GBK 解码。

支持 ASCII `[注解]`、样例中的 `〖注解〗`，以及手册文字层中的 `〚注解〛`：

- `HT` 后可带字号、字体或两者，如 `[HT5SS]`、`[HTH]`、`[HT12.50K]`。字体限 `SS`、`H`、`K`，映射为本工具的 serif、sans、kai。字体状态延续到后段；字号单位为 pt。段前样式写入块属性；段内变化写入 `marks: [{start,end,fontFamily?,fontSize?}]`，偏移按 UTF-16 code unit 计数，半开区间，与 JavaScript `slice` 一致。返回基础样式后不生成多余 marks；相邻相同样式合并。
- 常用号 `1..8` 按通行字号近似映射为 `26,22,16,14,10.5,7.5,5.5,5` pt。这是实现选择，不是恢复出的方正度量。明确磅数接受 `12.`、`12.25`、`12.50`、`12.75` 等，范围 5–72 pt；超出本工具范围的注解原样保留并警告。
- 无参数 `JZ` / `JY` 近似为当前整段居中 / 居右。每个换段符之后恢复左对齐。由于接口没有逐行对齐，此行为始终产生警告。
- 配对简单标题 `[BT(1]内容[BT)]` 至 `[BT(4]内容[BT)]` 转为 heading，附 `level:1..4`，与前后正文分块。仅恢复标题结构，PRO 文件定义的字号、占行和孤题规则不可用，明确警告。单边 BT、5–8 级、复杂参数、嵌套标题不保证可表示，保留未知注解。
- 仅整篇单一 `[FL(1]内容[FL)]` 至 `[FL(4]内容[FL)]` 可转为 `layout.columns`；开闭符必须同种，可带末尾结束符。局部、嵌套、带线型／栏距／拉平参数的分栏保留原文。简单分栏也警告未还原原引擎栏底拉平。
- `SJ` 缺省恢复两字缩进；如 `SJ5。3` 转为五号三字宽，即 `indentPt:31.5`；`SJJ2` 转为 `indent:2`（em）；`SJJ12p` 为 12 pt，`SJJ10mm` 换算为 pt。段前立即生效，段内只对后续段落生效，持续直到后续 SJ。只接受可表示的 0–20 em 或 0–144 pt，复杂字距保留。
- U+E004 分段，U+E003 转为段内换行，U+E005 作为结束标记移除；`〓` 转为 U+3000 全角空格。结束标记后的其他内容继续保留，并警告。
- 物理 CR/LF 不产生段落，按 BD 编辑源格式移除。普通纯文本应走纯文本导入，而非此函数。

未知注解、未闭合注解、不支持的字体变化、未知私用区字符及尚未解释的七位数字文件头均保留原文，并给出警告。`[HT]` 的恢复默认含义未确认，故保留。块类型输出 paragraph 或有显式 BT 证据的 heading；不根据字号猜测标题，也没有有证据的 pageBreak 语法。空段不会生成空块。没有结束符时照常导入并警告。

本次遵循 REA 的“观察／推断／未知”区分，仅检查用户提供安装包中的资料及少量样例，没有启动原软件，也没有验证原引擎渲染。以下 PDF 页号均是实际文件页号，含前言；括号中是手册印刷页码。安装包虽标为 11.0，所附手册标题为《书版2008 使用指南》，版本差异仍是未知项。

GBK 字节 `AA A4`、`AA A5`、`AA A6` 分别解码为 U+E003、U+E004、U+E005。当前 Node 的 WHATWG TextDecoder 对 gbk、gb18030 均验证出这三个值，测试使用自造字节，不含商业文本。其换行／换段／结束角色属于静态交叉推断。编码检测建议先严格 UTF-8，失败再严格 GBK/GB18030，并保留原始字节；私用区符号只能辅助判断，不能证明整个文件编码正确。不要使用替换错误的非严格解码而不提示；已经出现 U+FFFD 的数据无法由本解析器恢复。

`\\=`、`\\;` 等 ASCII 控制写法尚未确认，原样保留。分栏不是换页，不把 FL 或 U+E003 猜成 pageBreak。已在手册文字层限定检索“另页／另面／分页／强制页／换版”等，未获得明确的独立换页注解，结论仅限这份文字层。复杂表格、数学、图片、版心、标题定义、书眉、竖排、注释及字体回退均未实现。原生工具的 table/equation 能力不意味着可转换 BD 中对应的所有语法。
