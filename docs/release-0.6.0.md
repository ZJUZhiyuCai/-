# 0.6.0：Word 实稿兼容与 MCP 期刊校样

日期：2026-10-22。网站：https://inkq.online/shuye/ 。这是软件兼容与排版流程验收，不能替代作者审校或印厂签样。

## 修复

- 有界转换旧二进制 DOC、MathType OLE、EMF/WMF、单帧大 TIFF、Word picture-only 图组；保留来源摘要和公式 OMML。未知结构拒绝导入，不以删除内容换取成功。
- 可显式 `revisionPolicy: "accept"` 接受文字修订，默认仍拒绝未确认修订。未实现的结构修订明确报错。Word DrawingML 的 moveTo 不再误判为修订。
- 相同图片不同裁剪分别保留；图组保持源坐标与绘制顺序。修复自定义脚注标记、Symbol 乘号、希腊字母/中文回退、长公式和表格宽度、自定义奇偶页眉页脚。
- 新增 `plan_journal_layout` 和 `set_text_block_type`，线上工具总数 85。排版方案包括中英文首面角色、真实章节、图表与题注关联、子图网格、依据原始像素约束的尺寸。
- 增加缺图题注阻断，区分正文中的“图1展示了…”与图题；图前注、双语图题与图件一起排版。
- 新增在线 stdio 适配器 `mcp/remote.mjs`，实时获取服务器工具目录；增加 `responseMode: "summary"`，避免图像/PDF 重复挤占上下文；大稿件传输上限与 HTTP 文件限制对齐。只对只读请求重试网络异常。
- XeLaTeX 先生成 XDV，退出后再单独转换 PDF，避免大图解码与排版堆叠加导致 1 GB 服务内存溢出；对大幅纯 RGB PNG 直接嵌入压缩像素流，保留原图像素并通过像素逐字节一致性测试。
- 修复编辑器字体加载等待导致云工程初始化停滞；验证浏览器保存、历史版本恢复和自动排版入口。

## 验收方法

私有测试集为 7 篇 Word 稿件，含 684 个数学区。作者选择接受全部修订；另确认其中 1 篇原始 DOC 没有六幅原图。

通过真实 MCP SDK 客户端 → stdio → HTTP 服务执行导入、排版方案、dry-run、原子提交、章节读取、修订冲突、异步 PDF、逐页坐标、下载摘要。逐块比较原文、表格、图片、公式源和字样标记；原文件摘要不变。测试稿件、图片、PDF、令牌均不提交公共仓库。

测试脚本：`web/scripts/journal-batch-acceptance.mjs`。外部 manifest 提供路径及明确的预期阻断代码；缺图稿必须返回 `FIGURE_ASSET_UNASSIGNED` 和 `quality.status=BLOCKED`，不能按普通通过计算。

回归：网页 170 项通过；核心/MCP 80 项通过、1 项条件性跳过；服务器 Python 81 项通过、1 项跳过。框架与独立部署构建通过。隔离环境实稿 6 篇无预检错误、1 篇缺图阻断符合预期，共 70 页。第七篇在 1 GB 限制下通过，服务峰值 645 MiB；前六篇在同样限制下通过。已部署 `78d521a` 至 inkq.online/shuye，并使用线上端点逐篇复测通过相同的 6 正例 + 1 缺图阻断反例，共 70 页。临时令牌已撤销。

## 边界

- 完成 PDF 编译不等于可以发印。缺图稿仍不可完整出版，不补画或替代原图。
- 公式源和对象计数保留不等于已逐符号核准数学语义；原稿模板残留、手工正文式脚注、刊期/卷号/文章编号需编辑确认。
- `quality.productionReady` 不会因为基础检查通过而自动变为 true；本次不宣称完整 ISO PDF/X 独立认证或方正 FFX 全量兼容。
- 当前会话旧 Sites 插件仍报告 0.5.0 / 76 工具。服务器更新不能改写它的固定连接。请使用 [新版 MCP 配置](../examples/mcp-online-config.example.json) 连接自有服务器；旧插件不会自动获得新工具。
- 该实稿流程未自动组装整期目录、连续页码、封面或作最终签样。它提供每篇自动排版与可追溯校样，仍需整期编辑验收。

使用说明：[MCP 接入及流程](mcp.md)。
