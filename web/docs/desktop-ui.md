# 书页桌面工作区与品牌标志

项目库、整期编排与编辑器使用统一的深灰工具区、纸色预览和蓝色交互提示。界面面向桌面排版，主要动作围绕稿件、版式和校样组织，不新增移动端布局。

品牌标志由 Claude Opus 5.5 / high 以原生 SVG 设计：以排版文字行组成叶片，沿斜向中缝形成深浅两半。深色工具栏使用新叶绿 `#7CCB98`，纸面使用松墨绿 `#1E6A48`。绿色只作用于 logo，工作区的蓝色交互提示保持一致。

应用栏、封面印记、登录/账号页与编辑器共用 `public/brand/shuye-mark.svg#mark`，favicon 为单独优化的三行版本。SVG 与配色 CSS 均保留 Claude 交付的原始字节，不依赖字体、脚本或外链；Codex 负责样式接入、去除封面重复透明度与验证。[Claude 原始设计说明](desktop-ui/logo-design-claude.md)保留其设计意图、几何及色值。

## 对抗性审查与修正

桌面 UI 经 Claude Opus 5.5 独立复核，再由 Codex 检查代码、接入修复并执行以下验证。绿色 logo 由另一个 Claude 新会话设计；Codex 针对 SVG 内容、颜色继承、小尺寸显示、引用路径和导航进行接入审查。

- 整期方案没有变化时保存不再递增修订，避免让仍对应当前稿件的校样失效；历史预览发生修改时仍创建新修订。
- 校样通过方案 ID、方案修订、源稿修订与文章顺序绑定；过期或不匹配时收起下载和页码。
- 取消等待不会让迟到的启动/轮询结果重写界面。
- 恢复框架版说明与 MCP 页的有序列表编号；加深纸面辅助文字、提亮深色面板标签。
- 封面印记改为继承前景色的 SVG；阻止本页文章拖到目录外输入框时插入题名。
- 交付核对包含新增 logo、状态模块与状态测试，避免只提交已跟踪文件。
- 新 SVG 自带半叶透明度，移除封面原有的整体透明度，防止再次叠加。四个入口统一加载只匹配标志的颜色样式。
- 原始设计预览的尺寸阶梯有颜色优先级冲突，已在本地预览副本修正；原始设计稿和 SVG 保留不变。
