## 当前发布边界

- 用户工程使用 Site 登录身份隔离，元数据 D1、文稿与内嵌图片 R2。单工程 20 MB，列表最多 200 个项目；工程归档保留数据。
- 浏览器中 Ctrl+S/保存到云端为显式保存；本地有更改时暂停 agent 拉取。编辑输入获得焦点时也暂停拉取。
- PDF 通过浏览器打印生成，字体使用访问设备字体。没有云端 XeLaTeX、PDF/X、CMYK、专业拼版或同版保证。
- Word 导入是浏览器内的独立子集：基本段落/字符样式/横向合并表格/图片/注释，纵向合并和复杂公式提示损失。文件不上传。
- 尚无自由坐标图文框、框串接、图层、母版、原生飞翔文件及 EPUB/H5 多媒体输出。未完成全量性能、中文输入法、多浏览器及专业印刷验收。
- 生产部署状态以部署服务结果为准；本地测试不会自动证明生产登录和数据访问已通过。
