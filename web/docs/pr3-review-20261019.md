# PR #3 复核与补强（2026-10-19）

基于 `71422442f4a1c82d6f931be40a2b451d8989a3d6`，复核范围包括其中已包含的 PR #2 修复及新增的期刊 Web 生产链。

## 修复

- **校样读取与保存并发**：原实现只在读取文件前判断修订。读取 PDF、报告或页面坐标期间，另一个浏览器或 MCP agent 保存新修订，会使返回的 `stale` 与当前工程不一致。现在读取完成后再次核对修订；默认下载拒绝过期校样，明确允许下载旧版时也返回 `stale: true`。校样仍绑定其原始修订和摘要；该检查不承诺响应发送之后工程不会继续改变。
- **导入后的工程切换**：`ProjectConnection.open()` 在打开任务被另一次操作取代时返回 `false`。原导入界面忽略这一结果，仍改写地址栏并提示导入完成。现在保留当前地址和工程，并告知导入副本可从项目库取回。

两项问题均先由新增测试复现失败，再验证修复通过。
