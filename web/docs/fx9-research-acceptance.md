## 本轮实现

1. `inspect_founder_pdml`：新增只读 MCP 工具，检查真实 PDML XML 的命名空间、页面、母版、对象几何、文章引用和字体；分页返回明细，报告缺失页面原点、悬空引用及未实现效果。拒绝 DTD、实体声明、畸形 XML 和超限输入；不访问文件引用，不执行 XML，不改变工程。它是检查器，**不是原生文件导入/写回**。
2. 自由版面颜色支持 RGB、显式 CMYK 墨量及具名专色。CMYK 各通道和专色 tint 为 0–1；专色同时保存 CMYK 替代色。颜色在 MCP、母版覆盖、保存及历史记录中使用相同模型。
3. PDF 保留 DeviceCMYK、Separation 专色色版及对象 OPM 1 叠印；同一专色名的替代色冲突拒绝输出。裁切标记使用 K-only CMYK；报告列出实际颜色空间、专色色名和叠印对象。
4. 浏览器属性面板提供墨量、专色名/浓度和叠印开关。屏幕采用近似颜色，**没有 ICC 软打样或叠印预览**。PDF 独立渲染的叠印效果与屏幕预览不同是已声明的限制。
