# 原生资产与 Word 兼容导入的整合验证

Word 的修订、大图处理与原生 MTEF/EMF 导入使用同一条服务器入口。整合后保留逐对象来源、原始文稿摘要和拒绝不完整导入的检查。

- `inspect_journal_docx` 与 `import_journal_docx` 均接受 `revisionPolicy`，默认 `require-clean`；只有显式 `accept` 才接受修订。正文和脚注中的修订均计入 `sourceRevisions`，未接受时 `acceptedRevisions` 为 0，正式导入不创建项目。
- TIFF 支持单帧、受支持色彩模式、最多 125 MP；输出仍受 5 MB 单图上限约束。超限在解码前拒绝，大图 PNG 使用无重采样 PDF 嵌入。多帧、CMYK 或不能无损转换的位深继续阻断。
- 旧式公式保持原生 MTEF 来源与转换校验，EMF 保持原始资产、矢量 PDF 和预览之间的摘要绑定。未知记录不回退为截图或静默丢弃。
- 单行/单列组合图通过表格单元格保留独立图片；不合成为重新采样的整张图。Word 本身的裁切/正交旋转另有变换记录，不能因此声称全部原图像素均保留。
- 保存自动补入的通用书页页眉不会覆盖期刊首面和奇偶页眉；明确配置的页眉仍生效。

验证使用人工构造的公开测试及本地私有稿件。三篇真实导入分别保留 378/378 个旧式公式、16/16 张 EMF，以及 6/6 张图和 5/5 个 OMML 公式。大图样本通过真实鉴权 HTTP 的默认修订拒绝、显式接受、保存、重载及 PDF 下载摘要核对，导出为 12 页。该样本的两处原 Word 裁切仅去除纯白边缘，保留区域逐像素一致；其余图像全部像素一致。原稿和图件不随代码发布。

这验证了导入和校样链路，不是编辑批准或印前批准。出版字段、原稿疑点、部分版面留白和目标环境实测继续分别验收。整期 Word 的 UNO 运行时也须单独配置，不能用单篇 XeLaTeX 成功代替。

可复跑检查：`python web/journal-engine/run_tests.py`、`cd web && npm test`、Web/standalone 构建，以及 [期刊生产验收](journal-production.md)。缺少运行时的跳过项不计作通过。
