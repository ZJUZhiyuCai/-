# 书页 · 绿色标志

## 设计意图

**页即是叶。** “页”与“叶”同音。古籍本来就以“叶”计页：线装书里一张对折的纸称为“一叶”，版心折线把它分成前半叶和后半叶。英文里 leaf 也指书页。这枚标志就是一片“叶”：

- **行即叶形。** 叶片被三道水平间隙切成四行，像一段排进异形文本框的文字。叶形从排好的行里显出来，而不是另画上去的插图。
- **叶脉即版心。** 从叶基到叶尖的一条直线把叶片分成两半：前半叶用满色，后半叶用浅一级的同色，对应线装书的前后半叶，也对应一个对开页。
- **叶柄。** 短而微弯，在 16px 下仍然能先认出是叶子。

新标志完全推翻了原来的“书”字形，不依赖任何字体：只用两段圆弧、一条中缝直线和若干水平行线构成。

## 几何（48 × 48）

- 叶基 (12.5, 37)，叶尖 (40.5, 7)，中缝是两点连线，倾角约 47°。
- 左上缘是 R 23.54 的圆弧（矢高 12），右下缘是 R 27.89 的圆弧（矢高 9）。两侧刻意不对称，更接近自然叶片。
- 行间隙位于 y = 12–15、21–24、30–33，宽 3 个单位。16px 时正好是 1px 且落在整像素上，32px 时是 2px。
- favicon 针对小尺寸单独调整：叶片缩放 0.86，改为三行两隙，间隙同样落在 16/32px 的整像素上。

## 色值

| 名称 | 色值 | 用途 | 对比度 |
|---|---|---|---|
| 松墨 | `#1E6A48` | 浅底标志色（纸面 #f6f4ef、白底） | 纸面 6.0:1 |
| 新叶 | `#7CCB98` | 深底标志色（#1b1b1b / #2c2c2c） | 8.9:1 / 7.2:1 |
| 深林 | `#164F36` | favicon 底板 | — |
| 嫩芽 | `#A6DDB6` | favicon 后半叶 | 对底板 6.2:1 |
| 纸 | `#F6F4EF` | favicon 前半叶 | — |

后半叶的颜色是 `currentColor` 加 `fill-opacity: .7`，会跟着主色自动变化。它在纸面上约 3.2:1，在 #1b1b1b 上约 5.0:1。

## 文件与集成

- `shuye-mark.svg`：替换 `web/public/brand/shuye-mark.svg`。`<g id="mark">` 位于 48×48 坐标系内，现有的 `<use href=".../brand/shuye-mark.svg#mark"/>` 不用改。全部图形都用 `currentColor`。根元素带有 `color="#1E6A48"`，所以单独打开文件时显示为松墨色。
- `favicon.svg`：替换 `web/public/favicon.svg`。
- `brand-colors.css`：只给标志着色。选择器 `use[href*="shuye-mark.svg"]` 只匹配引用标志的 `<use>`，不会影响 `.wb-brand` 里的返回箭头等其他图标。

| 位置 | 选择器 | 颜色 |
|---|---|---|
| 项目库 / 整期工具栏 | `.brand-home` | 新叶 `#7CCB98` |
| 编辑器工具栏 | `.wb-brand` | 新叶 `#7CCB98` |
| 登录页 | `.auth-brand` | 新叶 `#7CCB98`（如果登录页实际是浅底，改用松墨） |
| 封面印记 | `.cover-imprint` | 松墨 `#1E6A48` |

- SVG 中没有脚本、事件处理器、`<style>`、外部引用、位图或字体。
- 16px 封面印记放在整像素位置时，行间隙最清楚。

## 预览

`preview.html` 可以直接在本地打开，包含：尺寸阶梯（16–96px × 四种底色）、工具栏/封面/登录/浏览器标签页的情景样稿、构成图，以及 16/24/32px 的像素放大镜（用 canvas 按实际像素栅格化后放大）。

Chrome 在 `file://` 下会拦截跨文件的 `<use href="x.svg#mark">`。所以预览页内联了一份与 `shuye-mark.svg` 完全相同的 `#mark` 用于着色演示，原文件则通过 `<img>` 直接展示。
