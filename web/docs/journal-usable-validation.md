# 从真实来稿到可审阅期刊校样

本轮以一篇已排版的中文期刊文章对照原始 Word 来稿，补齐通用产品能力。私人来稿、图片、PDF、账户配置和实际校样证据保留在本地，不进入仓库。

## 已补齐的链路

- 规范任务：未分类文稿 → 首面/章节识别 → 图题归属、表格与 DPI 约束 → dry-run → 原子版本 → 全文 PDF → 可定位问题 → 整次撤销。
- `compact-academic` 版型：170×240 mm，正文 8 pt / 10.8 pt，双栏间距 6 mm；首面通栏，三线表、公式编号与参考文献独立样式。
- 旧 DOC 保真：隔离转换后，独立读取原 Word 二进制正文、表格、字符样式与字段结果；仅在段落顺序确定、差异为纯插入缺失时恢复可见字符。保留转换稿的公式、表格、资产和已有上下标。隐藏文字不会复活；修订、替换、缺整段、复杂域内缺字及不支持的片段样式拒绝自动修复。
- 原始 DOC 的 SHA 不变；恢复内容和 WordDocument CP 位置留在导入报告。该读取器不等同于完整 Word 排版器，遇到无法核验的 DOC 应在 Word 中处理并另存 DOCX。
- 编辑预览遵循期刊字号，忽略导入 run 的字号/字体覆盖，保留斜体、粗体、上下标。首面能保留页底脚注。列宽重复校验不再制造浮点变化和假“未保存”。
- 未解决批注进入任务和 PDF 报告；历史缺图记录与当前图件状态分别呈现。详细来源记录默认折叠，待核对事项保持可见。

## 本地验证

- 真实文章：9 页，6 图、3 表、1 个原生公式、50 条参考文献；16/16 字体嵌入，143/143 对象映射，文字边界无越页。有效图像 DPI 最低 328.9。
- 旧 DOC 转换遗漏的 41 处、201 字符从原文件恢复，含拉丁物种名和统计符号；未用语言模型推测文字。
- 浏览器实际启动规范任务、查看报告、定位图件、下载 PDF；下载字节与校样 SHA 一致。撤销后与任务前整份工程深度相等，旧 PDF 下载被拒绝为 STALE_PROOF；再执行产生新版本。
- Web 全套 286 项、期刊引擎 141 项通过；追加的报告展示与原生 DOC 完整性检查有针对性复验。框架及独立服务构建通过。
- 对照 PDF 与候选均检查全部 9 页；候选 300 dpi 单页渲染，并核对首面、脚注、公式、三线表、参考文献局部。浏览器仍为结构编辑预览，最终分页以 PDF 为准。

## 仍需编辑判断

这次验证证明上述样本可以完成编辑校样闭环，不代表所有 DOC、期刊或正式印刷场景已通过。该样本原图存在烘焙题注、裁切和边缘质量问题，需要作者原图；软件保留来源，不擅自改绘或裁掉数据。局部图文留白、全文内容、公式语义仍需编辑审校；字体许可、PDF/X、印厂条件另行验收。规则整理与 LLM 自定义参数调整分别记载，不把固定规则宣称为模型智能设计。

二进制解析依据 Microsoft [DOC 文本读取](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-doc/01d5d8c4-cf9c-4ef9-80fd-439e763cfe01)、[字符属性](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-doc/7022285b-9621-42e9-ad4d-4e02c115ef18)及 [ToggleOperand](https://learn.microsoft.com/en-us/openspecs/office_file_formats/ms-doc/bc4ca98b-68ca-49dc-a091-1460e42d781e)。回归使用合成 CFB 流，无私人稿件依赖。
