# 跨稿件验证：组合图、化学字样与脚注

不同真实稿件暴露了单一数学样本未覆盖的问题。本轮修复了表格子图脱离原格、字符样式上下标丢失、正常文字公式单位空格消失、温度符号/Unicode 下标缺字，以及标题字重覆盖吞掉脚注正文。源文档和图片仅在维护者私有环境使用，公开测试全部为人工构造数据。

## 可由 AI 直接操作的对象关系

表格新增 `cellImages:[{row,col,imageId}]`。图片仍是独立 image 块，保持导入后的图像字节与稳定 ID；输出流只在所属格渲染一次。`width` 是单元格可用宽度的百分比。通过 `apply_changes/update_block` 修改归属，使用同一事务明确移走/解除图片后才能删除所在行列。插入行列同步重编号，合书同步重映射图片 ID。

支持普通格和横向合并起点，图片必须在格内文字之前。图片与文字交错、纵向合并中的图片、重复归属、缺失引用、图片本身另带题注或独立定位均被阻止。Word 显式无框线表格保留为 `borderStyle:"none"`，不用栅格线框住组合图。

图片表格可配置 `captionPosition:"below"`，用于图下注；数据表默认表上注。图组整体放在同页，按实际排版盒高度阻止超页，不靠缩放或裁切图像掩盖失败。`semanticLayout.cellImages` 返回逐图同页检查，`sourceObjectCoverage` 包含所有图片和 `note:<id>` 脚注/尾注正文的起止位置。语义坐标不能替代图中文字与遮挡检查。

## 导入和输出约束

- 只豁免精确的 `ADDIN EN.CITE.DATA` 非显示元数据域。`EN.CITE`、`EN.REFLIST`、REF 等空缓存域，以及未闭合域继续阻断；报告区分 `sourceFields`、`metadataFields`、`visibleFields`。
- 解析字符样式 `basedOn` 链中的上下标，直接设置的 baseline 取消继承；循环报错。这不是对全部 Word 样式继承的支持声明。
- OMML `m:nor` 正常文字运行保留显式空格，防止计量单位连写；原始 OMML 和摘要不变。
- Unicode 下标数字以 TeX 下标排字，源字符串保留；PDF 文本提取可能返回普通数字。℃/℉ 使用 CJK 字体，实际编译缺字仍为硬错误。
- 首面字重配置与参考文献标签处理只渲染一次正文；Word 上标脚注标号不再包住 TeX 脚注正文。脚注缺失也会触发源对象未定位错误。
- 横向合并单元格按自然行高排版，避免错误套用纵向合并的撑高逻辑。

## 本轮证据与尚未支持项

五篇不同 DOCX 完成导入探测，其中一篇实验类论文完成真实鉴权 HTTP 导入、保存、编译、逐页查询和下载：5/5 数学区、15/15 图像实例、6/6 源 Word 表、27 条文献；另加一个布局容器组织连续六子图。最终 9 页、115/115 对象（含脚注）可定位，15 条单元格图片关系和 7 条图表锚点通过，编译缺字/溢出、页面外文字为零，字体全嵌入。9 张 300 dpi 单页逐页检查。

初版 11 页经过锚点和行高校准为 9 页；正文、单元格文字、图像像素和公式源未删除或重画（源 TIFF 无损转 PNG，逐图验证 RGB 像素相同）。图像实际有效分辨率约 286–289 dpi，低于 300 dpi 门槛，质量状态仍为 **BLOCKED**。出版占位字段和源稿疑点需编辑裁定；不能把数值测试通过写成商业交付或发印通过。

另外四篇仍暴露旧 MathType/OLE、EMF、超 25 MP TIFF、修订未接受或字体编码符号等阻塞。它们没有被降级成警告或冒充完整导入。优先开发可追溯的 OLE/EMF 转换和受限大图处理，再扩大生产样本；修订处理与不明源文字应由编辑裁定。

回归命令见 [journal-production.md](journal-production.md)。新增 Python 测试涵盖真实 PDF 图片数、上下左右关系、脚注正文、超高图组拒绝、单位空格和缺字；Web 测试涵盖保存往返、AI 事务保护与合书重映射。
