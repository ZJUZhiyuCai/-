# 飞翔方向的 Web 产品范围与验收矩阵

研究日期：2026-10-16。本文件记录产品目标、迁移起点和验收门槛，不是通过报告。网站发布后的测试结果应另行记录具体构建版本、测试输入和实际结果，再更新本表。旧项目的方正书版 11 矩阵仅作历史记录，不再作为本产品的功能目标。

## 参考版本与证据边界

图书、期刊排版以官方公开下载页中的**方正飞翔印刷版 V9.0，构建 9.0-1794，更新于 2026-07-07**为版本基线。官方另于 2026-10-10 发布**机关文印版 V9.1**；这是另一产品分支，不能将印刷版直接写成 V9.1。[印刷版下载与产品介绍](https://www.founderfx.cn/product/1012.jhtml)、[官方新闻列表](https://www.founder.com.cn/News/Company/index.html)

印刷版、数字版和创意版的范围不同。这里优先评估书刊编排及印刷、电子书输出；H5 富媒体交互属于扩展范围，不因网页形式自动获得这些能力。[官方产品对比](https://www.founderfx.cn/product/productCenter.jhtml)

V9.0 官方功能页可确认对象框架、大纲、图说、公式、索引及 EPUB 等方向。细分操作可参考官方帮助页公开的旧版说明书，但旧版手册不能证明 V9.0 的全部精确行为。[V9.0 功能说明](https://www.founderfx.cn/product/161/2703.jhtml)、[官方使用说明入口](https://www.founderfx.cn/staticpage/help_center_manual.jhtml)

本轮没有取得飞翔 V9.0 的可运行对照环境、原生工程样本和同字体参考 PDF。因此当前只能证明独立功能与公开资料的范围对应，**不能宣称完整对等、原生格式兼容或版面一致**。不把官方宣传中的兼容性承诺转写成本项目承诺。

## 状态定义

- **本地已有（部分）**：`open-typesetter` 0.3.0 中存在可复用实现；不代表云端已接入，也不代表与飞翔等价。
- **Web 待验收**：功能须通过浏览器、部署端接口、持久化与输出用例后才能标记可用。仅拷贝源码、存在按钮或返回成功 JSON 不算通过。
- **未实现**：迁移起点不存在所述能力，不能用邻近功能代替。
- **参考待核实**：公开页面不足以确定最新版本的具体规则，需官方手册或合法对照样本。

下表的“Web 状态”是迁移开始时的研究快照，不能用作当前部署版本的实时状态。父任务完成实现后应逐项补充验收证据。

## 验收记录格式与发布约束

每项测试记录：功能 ID、提交版本、环境、输入文件摘要、操作步骤、预期、实际、结果、输出位置。自动化单测、浏览器交互测试、部署端端到端测试和飞翔对照测试分别计数。没有执行过的项目记为“未执行”，不得从代码检查推断测试通过。

可用网站的基础发布门槛包括：实际 HTTPS 页面可访问；核心编辑可完成；项目持久化与导出成功；无他人项目越权；错误可见；测试覆盖新建→编辑→保存→重开→导出链路。达到这个门槛只证明所声明的 Web 范围可用。

“完整对标”的门槛另含自由图文框、母版、长文档、专业输出、原生格式与电子出版的明确支持范围及相应用例。仍有上述核心缺口时，应如实发布为独立 Web 排版产品，并列出缺口，不能把上线完成写成飞翔全功能完成。
