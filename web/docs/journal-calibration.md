# 期刊实稿的版式校准

本次校准修复了公式密集稿件的多余留白与分页问题，在保留正文、公式、图表和脚注的前提下，将维护者私有的 14 页样稿收敛为 12 页。这里记录可复用的参数和回归方法，不包含客户稿件或作者信息。线上 DEMO 尚未部署此分支。

## 参考与参数

先测量实际参考 PDF，不能把“学术期刊”一律解释为双栏。这篇参考稿使用单栏正文；产品的双栏能力仍独立保留。170×240 mm，左右边距 13 mm，上下边距 16 mm，正文与数学字号保留 8.2 TeX pt；行距设为 `fontSize * lineHeight = 12.4` TeX pt。TeX pt 为 1/72.27 英寸，PDF 坐标 pt 为 1/72 英寸；对应正文基线间距约 12.354 PDF pt。

项目用 `layout.columns:1`、`layout.lineHeight:12.4/8.2` 和显式 `journal.mathFont:"stix-two"` 复现本轮校准配置。字体选择和完整元数据通过 `set_journal` 设置；其更新是完整替换，调用时保留已有刊名、卷期等字段。图件宽度按参考稿的实际物理尺寸分别设置，不能全图套同一个百分比。

## 修复与真实 PDF 回归

| 触发条件 | 修复后的行为 | 合成回归 |
| --- | --- | --- |
| ctex 默认 1.3 倍行距再乘模板行距 | 期刊模板使用明确的基线间距，字号不变 | 提取 PDF 两条正文基线，检查 12.4 TeX pt；表格字体仍为 8.2 pt |
| 标题后的钩子被段落样式分组恢复 | 后续正文可以正常分页，标题只约束需要相邻的首段 | 连续标题、三个长段和表格不会将半页内容一起推走 |
| 单栏标题前的近似空间检查引入伸缩胶 | 单栏使用实际剩余高度；双栏保留对应分栏处理 | 标题与前面的正文在有空间时留在同页 |
| 引导段与公式各自结束段落 | 正常单栏字号的正文与紧随公式共用 TeX 段落，保留两个源 ID | 没有额外空基线，引导句与公式同页 |
| 多个赋值位于同一个行内数学对象 | 只在最外层逗号/分号增加可断行点 | 分式、矩阵、上下标和成对括号内部保持原样，无丢值/越界 |
| 一个公式对象以关系符结束，下一对象继续推导 | 两段连续公式保持同页 | 页底不会只留下大于号，引导句也与公式同页 |
| 表格用整行高度当作字高，再加字深 | 短行按 1.25 倍字号确定基线间距；长内容仍可撑高行 | 实际短行距 10.25 TeX pt，表头、正文与希腊字母完整 |
| STIX 模式的传统数学字体命令调用西文字体 | 渲染时映射到 Unicode 数学字母表，原公式文本不改写 | 实际编译检查正体希腊字母与粗体数学符号，无缺字/字体替代消息 |

回归入口：仓库根目录执行 `python web/journal-engine/run_tests.py`，包含 `tests/test_journal_calibration.py`。需要 XeLaTeX；STIX 字体实测用例目前检查 macOS 系统字体文件，其他环境跳过该字体用例，因此普通 CI 绿灯不能证明部署主机已具备 STIX。部署前用实际所选字体编译样稿。

本轮本地结果：54 项原生引擎测试和 155 项 Web 测试通过，Workers/standalone 构建通过。公开合成稿通过真实鉴权 HTTP 导入、存储、编译及下载，输出 2 页、6 个数学区、2 条锚点和 29 个对象，旧修订下载被拒绝。私有实稿经保存后的工程重新导出，全文 12 页、295/295 数学区、491/491 对象、14/14 锚点；PDF 字体全部嵌入，零缺字/溢出编译消息，零页外文字。

## 成品边界

所有 12 页均作单页视觉检查，并核对连续不等式、矩阵和表内希腊字母的 300 dpi 局部成像。这个结果只绑定当前 PDF，不能替代后续改稿、换图、补出版字段或更换字体后的复验。

当前 7 幅图约 192–244 dpi，均需作者原图。出版字段和引用栏未最终确定，作者的数学语义终审、编辑验收、字体许可和指定印厂要求尚未闭合。质量报告继续返回 `BLOCKED` / `productionReady:false`。客户素材、原始证据、校样和具体字段候选仅在私有交付包中保存。正式替换原图后检查内容与标签一致性；补齐首面字段后全篇重排，不能强行锁页、删内容或缩公式来保持 12 页。
