# Web 0.5.0 · 已完成功能发布

2026-10-17。用户已授权先发布当前已完成的功能。此版本不以“方正飞翔完整对等”或“完整 PDF/X 认证”为名发布；此前报告中的整体验收结论继续有效。

## 本次提供

- 自由文字/图片/色块，串接文字流、自动续页、局部样式、多栏和基础竖排/异形排文。
- 母版继承、页面覆盖、内容槽、章节页码和左右起章。
- 结构流中的跨页表格、横纵合并、重复表头、超高行拆分、长脚注续排与尾注；浏览器、MCP 和 PDF 共用排版计划。
- 多字体嵌入、真实 ICC 转换、CMYK/专色/叠印、出血和裁切标记、受限 PDF/X-4 输出。
- PDML 原文保留编辑，以及显式页面原点的纯文本子集导入/写回；FFX 只读静态检查。
- 76 个 HTTP MCP 工具，修订冲突防护、原子修改、dry-run、云端保存和最近十版恢复。

## 使用入口

进入编辑器后点击“自由版面”。文字流中可启用表格与注释模式；“PDML 原文编辑”提供打开、定点修改和下载；“导出排版 PDF”需要用户提供有权嵌入的字体，ICC 转换另需适合印刷条件的 ICC。源码不包含厂商程序、私有字体、真实模板或用户文稿。

网站保留原有私有访问权限。开源使用者可依据 `README.md` 自行部署，配置自己的身份网关、D1 和 R2；公开模板不绑定维护者的 Site ID。

## 验证与限制

发布前自动测试 126/126 通过，标准生产构建成功。19 页跨页样稿通过实际 HTTP、浏览器修改/保存/恢复/下载、独立内容守恒和字形框界检查。PDF 独立子集检查通过，29 个负例按对应规则拒绝。详见 [逐项报告](native-rich-pdfx-acceptance.md)。

仍不支持完整 FFX 读写和飞翔原应用往返验证；PDML 变长文字及复杂原生重排未实现。结构流暂限横排矩形、相同列宽与字体度量，不支持所有竖排/异形表格与单元格富样式。PDF/X 没有完成全部 ISO 15930-7 独立合规验证，不提供认证结论。完整功能差距见 [矩阵](feixiang-matrix.md) 与 [PDF/X 验证边界](pdfx-validation-acceptance.md)。
