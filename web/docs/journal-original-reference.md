# 原刊对照校准与 AI 可控版式

原始出版 PDF 与先前派生校样的版心不同。原刊页面为 216×303 mm，未显式声明裁切框；本次继续使用项目的 170×240 mm 样稿规格，横纵位置分别按页面比例测量，字形与图件保持比例，不把归一化视为确认了原刊裁切尺寸。先前 13 mm 等宽左右边距和 16 mm 上边距不能作为原刊参数。

私有参考稿使用单栏，具有首面中英文引文栏、镜像页眉和五处图文并排。新的候选保留原 Word 内容，在 170×240 mm 上使用约 133.73 mm 版心、内外边距 19.71/16.56 mm、正文顶边 29.4 mm、底边 18.5 mm。正文与数学字号仍为 8.2 TeX pt，行距 12.63 TeX pt。它是 13 页候选，原刊为 12 页，**尚未达到逐页等价或收费交付验收**。没有删内容、缩数学字号或降低印前门槛来凑页。

## 可保存、可通过 MCP 设置的控制项

`set_journal` 仍为完整替换；调用前读取工程并保留已有字段。新增选项都经过服务端 schema 与浏览器模型校验：

- `roleStyles`：以现有角色为键，可覆盖 `fontSize`（6–24 TeX pt）、`leading`（7–36 pt）、`spaceBefore`（0–36 pt）、`spaceAfter`（0–24 pt）、`fontFamily`（serif/sans）、`bold`。标题与引用栏不再只能套一个硬编码尺寸。
- `bodyWeight`（regular/light）：light 只适用于已安装思源字体的服务器；`headingFamily`（serif/sans）；`captionBold`。字体可用性仍须实际编译核对。
- `headSepMm`（2–12 mm）：在 geometry 计算前设置，改变页眉间距不会额外移动正文；`pageNumberStyle`（plain/dots）和 `yearSuffix`。
- `articleNoteId`：引用已有脚注，收稿、基金、作者信息采用标签与悬挂缩进；作者行标记保留，页脚不再给收稿日期多加一颗星。脚注文字不修改。
- `inlineDisplayThreshold`（0.65–0.95）：以可用行宽比例控制长行内公式何时独立成行，不缩放公式。
- `tableWidthPercent`（70–100）：居中表宽占版心的比例。表格现有 `align` 控制单元格对齐，字号与单元格内容保留。使用现有 `columnWidths` 把空间分配给实际长单元格；校准样的短方案列不再挤占描述列，排序列留足完整不等式的宽度。

参考文献序号现在放进固定宽度标签盒，第一行与续行正文真正对齐。连续的单栏公式在一个可分页的显示组中排版，消除额外文本基线；源公式 ID、编号、后缀与表达式保留，关系符续接处禁止分页。双栏继续使用对应栏位和续接约束。

## 有界图文并排

给图片同时设置 `wrap: "left" | "right"`、`width: 15..60`、`sideTextIds` 和范围内 `anchor`。`sideTextIds` 是按正文顺序排列的连续段落/公式 ID，最多 32 个。题注继续通过 `captionIds` 绑定。MCP 的 `update_block` 可以原子设置这些字段；编辑器图片属性提供范围多选与应用按钮。

整个并排组同页输出，文字与图件占用独立的实际宽度，窄侧公式按测量宽度断行。范围不能重叠、跨越标题或其他图表、含脚注或嵌套锚点；过高的组会明确编译失败。只有 `wrap` 而未给出范围时，PDF 会报错，不能静默丢掉环绕要求。`semanticLayout.sideGroups` 返回同页覆盖结果；它是语义定位，不是墨迹碰撞认证。

这是一种边界明确的并排排版，**不是**任意轮廓绕排或自动跨页浮动优化。浏览器编辑预览与 PDF 仍独立分页，交付须验最终 PDF。

## 验证与尚未闭合的条件

本地 59 项原生引擎测试、158 项 Web 测试通过，Workers 与 standalone 构建通过；公开合成稿经鉴权 HTTP 导入、保存、编译、下载通过，旧修订被拒绝。新增实际 PDF 回归覆盖左右并排、全文对象保留、过高组失败、页眉修改不移动正文、参考文献悬挂和出版脚注标记。

私有实稿：295 个数学区保留；244 个原始模型块的内容与脚注未改变，另加 2 个出版引文块；7 图、7 表、184 个单元格、34 条参考文献保留；493 个对象均定位，14 条锚点通过。字体嵌入，无缺字或越界编译消息。私有原稿、作者信息、图件和成品不进入仓库。

原刊与 Word 存在科学内容和出版字段差异；原刊仅作为版式参考，不覆盖 Word。原刊内嵌位图与页面成像上的标注也不完全一致，抽取位图不能视为取得了完整出版图件。当前图 1、3–7 在实际尺寸下仍低于 300 dpi，图 2 约 305 dpi 但仍需标注核对。文章编号与最终刊期/页段须编辑确认，数学语义与图件标注须作者校对，印前要求尚未闭合；`productionReady:false` 保持有效。本分支尚未部署线上 DEMO。
