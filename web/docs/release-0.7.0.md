# 0.7.0 整期编排验收

整合 InkQ 的整期工作流程：在书页选择并排序文章，按实际渲染结果回算目录，导出整期及逐篇可编辑 Word、整期 PDF、报告和交付包。源工程与方案修订绑定，历史恢复创建新修订；旧源稿或旧方案的校样默认禁止下载。

新增六个 MCP 工具，总数 91。浏览器与 agent 使用相同服务；跨会话可取回最近任务。用法见 [整期指南](issue-composition.md)。

## 结果边界

红橙旧 DOC 缺少六幅原图，测试要求准确保留这六项 `FIGURE_ASSET_UNASSIGNED` 阻断，不以自动生成图片代替。该期可生成供编辑审校的完整交付物，但不能判为可直接发印。其他稿件状态为 `REVIEW`；编辑逐字与公式语义签样、完整 PDF/X 及印厂接收仍需独立验收。

本版本支持横排期刊模型；自由版面、竖排、尾注模式、注音与侧排等未支持的 Word 表达会明确拒绝。Word 在不同字体或办公软件版本下可能重新分页。
